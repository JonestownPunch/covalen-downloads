# Covalen signed downloads

This repository distributes signed Covalen release assets and release metadata. It does **not** contain the Covalen product source. GitHub's automatically generated source archives for this repository contain only this distribution metadata.

The authoritative v0.1.1 product source identity is the source commit recorded in the signed candidate manifest and keyless signature bundle. Verify a downloaded asset against the SHA-256 values and expected signer identity in the relevant [release notes](releases/v0.1.1.md), using a signer identity pin received through a separate trusted channel.

Covalen is all rights reserved. Downloading an asset grants no permission to use, copy, redistribute, or deploy it. Obtain written permission from Covalen for an evaluation. The R4.4 predecessor asset is an acceptance-only fixture, not a supported deployment release.
